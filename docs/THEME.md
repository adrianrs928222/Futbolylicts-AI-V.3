# Tema visual Futbolylicts-AI

Tema comercial oscuro con identidad azul + verde.

- Fondo: negro/azul muy oscuro.
- Azul: navegación, acciones y botones con degradado hacia negro.
- Verde: confianza, estados positivos y marca secundaria.
- Tarjetas: cristal oscuro, bordes suaves azules y brillo controlado.
- Diseño responsive para móvil, tablet y escritorio.
- Sin dependencias CSS externas.

Paleta principal:
- `#02050a` fondo
- `#198cff` azul principal
- `#0057e7` azul profundo
- `#20f08a` verde principal
- `#39d7ff` cyan de apoyo
