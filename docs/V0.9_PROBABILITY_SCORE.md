# v0.9 — Probabilidad + nota

> **Documento histórico.** Las reglas canónicas vigentes están en `docs/RULES.md` y `docs/FUTBOLYLICTS_PROMPT.md`.


- Un pick automático necesita **probabilidad >= 75%** y **nota >= 8.0/10**.
- El núcleo preferido combina **nota >= 8.5** y **probabilidad >= 78%**.
- Una probabilidad del 75% no se traduce automáticamente en una nota 8.5.
- La interfaz muestra **“Qué puede hacer fallar el pick”** con lenguaje natural.
- Se mantienen las mejoras v0.8 de shortlist, The Odds API para cuotas y reservas solo en Eerste Divisie.
