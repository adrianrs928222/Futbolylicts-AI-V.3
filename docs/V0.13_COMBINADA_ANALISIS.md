# v0.13 — Combinada del día desde los analizados

- Si existe una combinada oficial con cuotas reales, se mantiene como primera opción.
- Si todavía no existe una combinada oficial, la cabecera **Combinada del día** muestra hasta 5 picks ALTA/MUY ALTA extraídos directamente de los partidos analizados.
- Para entrar en esta selección visual se exige a la vez **≥70% y ≥8.0/10**. MUY ALTA sigue siendo **≥78% y ≥9.0/10**.
- Una cuota ausente no oculta un pick estadísticamente fuerte: aparece como **Sin cuota API**.
- Nunca se inventa una cuota ni se calcula una cuota total si falta precio real en alguna pata.
- Todos los partidos de hoy, los analizados y el detalle de cada análisis siguen visibles.
