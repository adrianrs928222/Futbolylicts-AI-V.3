# v0.14 — Combinados del mismo partido + +2.5 con peso real

Esta versión amplía el universo de mercados del motor sin cambiar la filosofía Futbolylicts-AI.

## Nuevos combinados analizados

El motor calcula de forma conjunta, marcador por marcador, estos mercados:

- 1X + Más de 1.5 goles
- X2 + Más de 1.5 goles
- 1X + Más de 2.5 goles
- X2 + Más de 2.5 goles
- Gana local + Más de 1.5 goles
- Gana visitante + Más de 1.5 goles
- Gana local + Más de 2.5 goles
- Gana visitante + Más de 2.5 goles

La probabilidad conjunta **no se obtiene multiplicando dos porcentajes como si fueran independientes**. Se calcula sobre la distribución de marcadores del modelo Poisson.

## Más de 2.5 goles

+2.5 sigue siendo un mercado de primera clase. Recibe peso de valor en el ranking y puede ser el pick principal cuando pasa simultáneamente probabilidad + nota. No se baja automáticamente a +1.5 si +2.5 sigue siendo ALTA/MUY ALTA.

## Cuotas de combinados

The Odds API v4, con el endpoint usado por el proyecto, no proporciona una cuota de Bet Builder / Same Game Parlay para estos combinados. Por eso Futbolylicts:

- sí analiza el combinado y muestra probabilidad + nota;
- sí puede proponerlo entre los picks visuales si es ALTA/MUY ALTA;
- nunca inventa su cuota;
- muestra `Sin cuota API` para que la cuota real se compruebe en Bet365.

Los mercados simples siguen usando cuotas reales de The Odds API cuando están disponibles.
