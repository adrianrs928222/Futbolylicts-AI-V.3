# Motor cuota 8 sólida — v0.5

La v0.5 cambia el objetivo de "llegar a cuota 8 con muchas patas buenas" por "llegar a cuota 8 con el menor número razonable de patas realmente fuertes".

## Reglas nuevas

- La combinada oficial usa **4–6 selecciones**.
- Se priorizan claramente picks de **8.5/10 o más**.
- Puede entrar como máximo **1 pick de 8.0–8.49**, y solo si además aporta valor real: cuota >= **1.45** y probabilidad estimada >= **72%**.
- Se mantiene el rango normal de cuota individual **1.25–1.75**.
- BTTS Sí mantiene cuota mínima **1.35**, pero ya no tiene límite de cantidad.
- El objetivo total sigue siendo **8.00–10.00** (aceptación técnica hasta 10.80 si no existe una opción dentro del rango principal).
- Si hacen falta 7, 8 o 9 partidos para llegar a 8, **esa combinación ya no se publica como oficial**.

## Por qué

Cada partido adicional es otro punto de fallo. Incluso si cada pick individual tiene una probabilidad alta, la probabilidad conjunta baja al multiplicarlos. Por eso la interfaz muestra ahora la **probabilidad combinada estimada** y deja de presentar una etiqueta simplista de "confianza global ALTA".

La probabilidad combinada se calcula como una aproximación multiplicando las probabilidades estimadas de picks de partidos distintos. Es una referencia orientativa y no una garantía.

## Bet Builder protegido

El motor puede priorizar un Bet Builder protegido cuando el proveedor entregue una **cuota real** para ese mercado. Nunca se inventa una cuota combinada para alcanzar el objetivo.
