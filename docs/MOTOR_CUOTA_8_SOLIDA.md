# Motor @8 sólido — v0.19

Después de construir la primera combinada, `combo.ts` ejecuta hasta 3 pasadas de revisión. Compara mercados del mismo partido, sustituciones con partidos descartados, eliminación o incorporación de patas. Un cambio solo se acepta con mejora mínima de calidad. Si la combinación estaba en @8–@10, puede bajar hasta el suelo blando configurado (@7.5) únicamente cuando la mejora de calidad sea real.
