# v0.10 — análisis visible

> **Documento histórico.** Las reglas canónicas vigentes están en `docs/RULES.md` y `docs/FUTBOLYLICTS_PROMPT.md`.


La web ya no oculta los partidos que fueron analizados pero no entraron en la combinada.

## Qué cambia

- Nueva sección **PARTIDOS ANALIZADOS / Qué ha visto el motor**.
- Muestra cada partido profundizado aunque no pase el filtro final.
- Para cada partido enseña el mejor mercado observado, probabilidad, nota, cuota y estado.
- Estados: **PASA EL FILTRO**, **CERCA DEL CORTE**, **FALTA CUOTA** y **NO ENTRA**.
- Explica de forma natural por qué no entra: probabilidad inferior a 75%, nota inferior a 8.0 o cuota fuera de @1.25–@1.75.
- Si el análisis estadístico ve una opción fuerte pero The Odds API no devolvió cuota, se muestra como **FALTA CUOTA** en vez de desaparecer.

## Regla del motor

Un pick oficial sigue necesitando simultáneamente:

- probabilidad >= 75%;
- nota final >= 8.0/10;
- cuota real útil, normalmente @1.25–@1.75.

La probabilidad no se convierte automáticamente en nota. La nota cruza forma, muestra, clasificación, contexto competitivo y valor de la cuota.

## ChatGPT / OpenAI

Esta versión no hace depender la web de ChatGPT. El motor sigue siendo determinista y auditable. Una integración con OpenAI puede añadirse después como segunda opinión, pero requeriría una clave de OpenAI API separada de la suscripción de ChatGPT y tendría coste propio.
