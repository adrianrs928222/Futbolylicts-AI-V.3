# v0.8 — shortlist inteligente

> **Documento histórico.** Las reglas canónicas vigentes están en `docs/RULES.md` y `docs/FUTBOLYLICTS_PROMPT.md`.


Corrige el caso en el que un sábado había cientos de fixtures, se analizaban solo 12 de competiciones poco útiles y The Odds API quedaba en 0 créditos usados.

Cambios:
- UEFA Champions/Europa/Conference se reconocen de forma exacta; AFC/CAF/etc. ya no ocupan esos slots.
- Antes de pedir forma/standings, se priorizan competiciones que The Odds API reconoce.
- Se priorizan Premier League, LaLiga, Serie A, Bundesliga, Ligue 1, Eredivisie, Eerste Divisie y otras ligas relevantes por país.
- La criba usa límites por categoría para impedir que una sola categoría monopolice los 12 análisis profundos.
- Las reservas siguen permitidas únicamente en Eerste Divisie.
- Si The Odds API no puede listar deportes activos, el sistema cae a prioridad local sin inventar picks.
