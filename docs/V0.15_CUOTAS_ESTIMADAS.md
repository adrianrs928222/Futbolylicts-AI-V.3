# v0.15 — Cuotas estimadas visibles

Cuando The Odds API no devuelve una cuota real para el mercado que el motor considera mejor, Futbolylicts ya no deja el precio vacío.

## Regla

- Cuota real disponible: `@X.XX REAL`.
- Cuota real ausente: `@X.XX EST.`.
- La cuota estimada es una **cuota justa orientativa**: `1 / probabilidad del motor`, con límites técnicos de @1.05 a @20.00 y redondeo a dos decimales.
- Ejemplos: 80% → @1.25 EST.; 78% → @1.28 EST.; 70% → @1.43 EST.

## Importante

La cuota EST. no intenta adivinar el precio exacto de Bet365. Sirve para orientarse, comparar mercados y calcular un total aproximado de la combinada. No se utiliza para validar el edge de +3 puntos ni convierte una selección en pick oficial con cuota real.

Las cuotas estimadas se muestran también en las alternativas de cada partido, incluidos 1X, X2, 12, BTTS, +1.5, +2.5, goles de equipo y combinados del mismo partido.
