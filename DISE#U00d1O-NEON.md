# Diseño Neon · El Maestro del Fútbol

Esta edición mantiene el motor de Futbolylicts-AI y cambia la presentación visual para acercarla al concepto neon/cyber mostrado en la referencia.

Incluye:
- Cabecera grande Futbolylicts-AI con **EL MAESTRO DEL FÚTBOL**.
- Cerebro + corona como identidad visual.
- Paleta neon cian, violeta, rosa y dorado.
- Navegación glassmorphism.
- Tarjetas especiales para Combinada del Día y Combinada BTTS.
- Tarjetas neon para ligas, picks, historial y partidos analizados.
- Responsive para móvil, tablet y escritorio.
- No cambia API-Football, Supabase, ML, caché ni lógica de combinadas.
