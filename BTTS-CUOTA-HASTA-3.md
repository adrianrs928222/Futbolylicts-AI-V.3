# Regla BTTS

La COMBINADA BTTS selecciona candidatos BTTS_YES con probabilidad >= 70%, score >= 8.0 y cuota <= 3.00.
No se descarta una selección por tener una cuota superior a 1.90 si mantiene ALTA/MUY ALTA confianza.

Nota: en la versión actual las cuotas mostradas por el motor son EST. calculadas por el modelo. Una cuota real de bookmaker solo puede aparecer si se activa e integra The Odds API en el flujo de análisis.
